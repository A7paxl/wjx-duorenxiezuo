# 公共仓

多人协作空间的公共载体。**公共仓装全组共用、全员可见；每人另有一个自己的个人仓，装个人过程。** 本试点工作区有 1 个公共仓 + 2 个个人仓：`个人仓/甲`、`个人仓/乙`；真实项目每人一个个人仓。

**可见性**：公共仓全员可见；个人仓之间互相不可见，每个人只能看自己的个人仓；个人仓之间只通过公共仓交换区的出件箱/收件箱接收内容。

## 目录

| 目录 | 装什么 |
| --- | --- |
| `00-入口/` | 项目共识、规则索引、README、AGENTS.md、公告栏 |
| `01-成员与规则/` | 成员名册、协作契约、命名规范、任务包标准、写回权限表、单据模板 |
| `02-推进管理/` | 当前推进、每人工作台、通知台账、任务看板、三本索引 |
| `03-交换区/` | 每人一个出件箱 + 一个收件箱；正件、指向消息、交换台账 |
| `04-知识区/` | 静态知识、动态知识、归集产出 `current/`、`history/` |
| `05-工具箱/` | 脚本、skills、提示词库、经验库 |
| `06-归档/` | 阶段快照与冻结的现状文件 |

## 交换区

- 出件箱：`03-交换区/出件箱/<姓名>/`；正件留发起人出件箱。
- 收件箱：`03-交换区/收件箱/<姓名>/`；只放一条三行指向消息。
- 个人仓的 `05-单据/` 只放副本；正本全空间只有一份，在公共仓出件箱。
- 投递四动作：写出件箱、写收件箱、提交推送公共仓、触发钩子；全成或全不成。
- 单据命名五段：**日期-发起方-接收方-主题-类型**。

## 个人工作台

每个成员在 `02-推进管理/工作台/` 下有一块个人工作台，由 `同步工作台.py` 从本人个人仓任务状态生成。工作台只放状态、阻塞、产出位置和更新日期，供外圈、业务方和评审查看；**个人仓仍是过程源，工作台是只读快照**。

## 快速开始

```bash
# 甲投递：正件放公共仓出件箱，指向消息放乙收件箱
python3 05-工具箱/scripts/投递.py --from 甲 --to 乙 --type 协同单 \
  --主题 机制口径确认 --动作 请求确认 --正件 ../个人仓/甲/01-草稿/协同单_机制口径.md

# 乙回执（乙在本人机器上；本地演练用 --个人仓 指向外部临时仓）
python3 05-工具箱/scripts/回执.py --from 乙 --to 甲 \
  --原单 <单号> --产出 <产出路径>

# 甲归集
python3 05-工具箱/scripts/归集.py --成果 <产出路径> --名称 机制口径说明.md --来源单 <单号>

# 收工
python3 05-工具箱/scripts/收工.py --成员 甲 --message "甲 收工"
```

规则以 `01-成员与规则/协作契约.md` 为准；AI 的读法与写法见 `AGENTS.md`。
