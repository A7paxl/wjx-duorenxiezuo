# 公共仓

多人协作空间的公共载体。**个人过程在每人自己的个人仓，公共仓只装全组共用、可被所有人查看的内容。**

## 目录

| 目录 | 装什么 |
| --- | --- |
| `00-入口/` | 规则索引、给人和给 AI 的入口说明 |
| `01-成员与规则/` | 成员名册、协作契约、命名规范、任务包标准、写回权限表、单据模板 |
| `02-推进管理/` | 当前推进、每人工作台、通知台账、任务看板、三本索引 |
| `03-交换区/` | 交换台账；单据正本留在个人仓出件箱，收件箱只放指向消息 |
| `04-知识区/` | 静态知识、动态知识、归集产出 `current/`、`history/` |
| `05-工具箱/` | 脚本、skills、提示词库、经验库 |
| `06-归档/` | 阶段快照与冻结的现状文件 |

## 个人工作台区

每个成员在 `02-推进管理/工作台/` 下有一块个人工作台，由 `同步工作台.py` 从本人个人仓的任务状态生成。工作台只放状态、阻塞、产出位置和更新日期，供外圈、业务方和评审查看；**个人仓仍是过程源，工作台是只读快照**。

## 单据怎么走

- 跨人协作只用三种单据：协同单、回执、退回单。
- 正件留在发起人的个人仓出件箱；接收人的个人仓收件箱只放一条指向消息（正件路径、动作类型、日期）。
- 公共仓 `03-交换区/交换台账.md` 只记交易，不存正本；全空间正本只有一份。
- 发起人验收后才归集进 `04-知识区/current/`；同名旧版先进 `history/`。

## 快速开始

```bash
# 1. 在个人仓建任务包（复制 00-任务包/00-任务包模板）
# 2. 投递：公共仓/05-工具箱/scripts/投递.py
python3 05-工具箱/scripts/投递.py --from 甲 --to 乙 --type 协同单 \
  --主题 机制口径确认 --动作 请求确认 --正件 ../个人仓/甲/01-草稿/协同单_机制口径.md

# 3. 收工：同步工作台、重建看板与索引、巡检
python3 05-工具箱/scripts/同步工作台.py --成员 甲
python3 05-工具箱/scripts/重建看板.py
python3 05-工具箱/scripts/巡检.py
```

规则以 `01-成员与规则/协作契约.md` 为准；AI 的读法与写法见 `AGENTS.md`。
