# Skill：项目共识维护

## 什么时候用

项目范围、目标、术语、角色、交付物或规则发生变化时。

## 先读

1. `00-入口/项目共识.md`
2. `01-成员与规则/成员名册.md`
3. `01-成员与规则/协作契约.md`
4. `01-成员与规则/写回权限表.md`
5. `04-知识区/静态知识/术语与口径.md`
6. `02-推进管理/当前推进.md`

## 步骤

1. 判断改的是哪一层：项目共识 / 成员与规则 / 术语口径 / 当前推进。
2. 写明改动、原因、影响谁；涉及权限或规则的，先让统筹确认。
3. 只改对应文件，不把同一信息复制到多处；其他位置只引用。
4. 在 `00-入口/公告栏.md` 发一条宣告：改了哪份、生效日期、影响谁。
5. 跑 `05-工具箱/scripts/巡检.py` 和 `05-工具箱/scripts/校验.py`。
6. 提交公共仓，提交说明写清改了哪份共识。

## 边界

- 规则只有统筹能改；AI 不代替统筹拍板。
- 不改个人仓；需要成员配合的，走协同单。
- 保密数值不进公共仓。
