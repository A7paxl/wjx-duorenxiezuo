# Skill：新成员工作区初始化

## 什么时候用

新成员加入，统筹已在名册登记之后。

## 步骤

1. 确认名册已有此人：岗位、职责、口径在谁手里。
2. 在公共仓建交换口、工作台、公告：
   ```bash
   python3 05-工具箱/scripts/建个人仓.py --成员 <姓名> --岗位 <岗位> \
     --职责 <职责> --口径 <口径> --路径 <本人机器上的路径> --登记
   ```
3. 脚本会：建个人仓骨架、复制任务包模板、写个人仓 AGENTS、建出件箱/收件箱、工作台、公告。
4. 新人在本人机器上设置 git 身份并提交个人仓。
5. 新人复制 `05-工具箱/提示词库.md` 的“我是新人第一次用”。
6. 统筹跑 `巡检.py`，确认两仓和名册一致。

## 边界

- 个人仓放在新人本人机器上，不往本试点工作区加仓；本试点现有公共仓 + 甲/乙两个个人仓。
- 个人仓之间互相不可见；只经公共仓交换区出件箱/收件箱接收内容。
- 新成员第一次建仓前，必须先由统筹登记名册。
