# 工具箱

AGENTS.md 只写工具在哪：AGENTS.md → skills 列表 → 具体 skill。

## 核心组件

| 组件 | 核心功能 | 应用场景 |
| --- | --- | --- |
| Skills | 维护项目共识、初始化新成员工作区、拉输入清单、阶段收口 | 项目体系治理；新人入组 |
| Hooks | 触发通知与脚本 | 个人仓提交→同步工作台；公共仓提交→巡检/收件通知；台账新条目→通知 |
| 提示词库 | 降低新人上手成本 | 不熟悉 AI 工作方式的成员按场景复制 |
| YAML 头与脚本校验 | 把非结构化信息转成结构化数据，确保规范 | 任务状态、单据、工作台、看板 |
