# Hooks

钩子只做固定动作：通知、同步、重建、巡检；内容判断仍由 AI，确认由人。

## 三个节点

| 节点 | 触发 | 动作 |
| --- | --- | --- |
| 个人仓 post-commit | 本人收工提交 | `同步工作台.py --成员 <姓名>`；把个人仓任务状态写成公共仓工作台 |
| 公共仓 post-commit | 公共仓收到提交 | `巡检.py`；`收件通知.py`；`模拟通知.py`（真实环境替换为京ME） |
| 通知台账新条目 | 投递/回执/退回/归集后 | 推送给对方；本试点用 `模拟通知.py` 输出 |

## 安装

```bash
python3 05-工具箱/scripts/安装钩子.py --成员 甲
```

个人仓钩子写入本人个人仓 `.git/hooks/post-commit`；公共仓钩子写入公共仓 `.git/hooks/post-commit`。

## 模板

- `post-commit.personal`：个人仓钩子模板。
- `post-commit.public`：公共仓钩子模板。

## 边界

- 钩子不自动提交内容；只做同步/重建/巡检/通知。
- 公共仓钩子不递归提交，避免提交风暴。
- 京ME 接口未接入；本试点用模拟输出，真实环境替换 `模拟通知.py`。
