# 任务包标准

每个任务在个人仓建一个任务包，六件一次建齐；暂时没有内容的先放空模板。

| 件 | 内容 |
| --- | --- |
| `任务说明.md` | 目标、上游单据、验收标准、明确不做 |
| `输入清单.md` | AI 开工只读清单里的文件；静态知识默认全读，动态知识按任务筛，个人知识由本人挑 |
| `待裁决事项.md` | AI 拿不准或本人也定不了的问题；空表也有意义 |
| `过程记录.md` | 日期、动作、结果、证据；只追加，失败也记 |
| `工作产出/` | 草稿 V1、V2……都挂在任务下；确认后进 `03-生效区/` |
| `任务状态.yaml` | 任务名、上游单据、状态、阻塞原因、产出、更新日期；字段统一，脚本可读 |

## 任务状态

| 状态 | 什么时候进入 |
| --- | --- |
| 未开始 | 任务包建好，还没开工 |
| 进行中 | 开工；阻塞解除；验收被退回需要返工 |
| 阻塞 | 等别人裁决或提供输入；`阻塞原因` 写明在等哪张单 |
| 待本人确认 | 草稿写完，等本人确认 |
| 已生效 | 本人确认，产出进 `03-生效区/` |
| 已交回 | 回执已发给发起人 |
| 已完成 | 发起人验收并归集；没有上游单据的任务，生效即完成 |

进度只认任务状态文件；接收人内部做到哪一步，只反映在本人任务状态里，单据上没有“处理中”这种状态。
