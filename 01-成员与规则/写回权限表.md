# 写回权限表

| 层 | 范围 |
| --- | --- |
| 自动写回 | 本人个人仓的过程件；脚本产物：本人工作台、通知台账、任务看板、三本索引；人不手写脚本产物。 |
| 确认后写回 | 生效版本、投递（含写进对方收件箱的指向消息）、回执、退回、归集；统筹另有当前推进、决策记录、公告与规则文件。 |
| 禁止写回 | 他人的个人仓、出件箱与工作台；统筹以外的人改规则文件；绕开脚本手工改交换区或工作台区；任何文件写入保密数值。 |

## 配套边界

- **看得见**：公共仓全员可见（含每人工作台）；个人仓只有本人可见。
- **AI 读什么**：公共仓 + 本人个人仓 + 输入清单；清单外不读。
- **能写什么**：本表；协作动作一律调 `05-工具箱/scripts/`。
