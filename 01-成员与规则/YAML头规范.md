# YAML 头规范

> 目的：把非结构化信息转成结构化数据，脚本可读、可校验。新文档从模板开始；旧文档用 `迁移YAML头.py` 补齐。

## 格式

Markdown 第一行必须是 `---`，字段一行一个 `key: value`，再用 `---` 结束：

```markdown
---
类型: 协同单
单号: 20261029-甲-乙-机制口径确认-协同单
发起人: 甲
接收人: 乙
状态: 已投递
更新: 2026-10-29
---

# 协同单
...
```

日期用 ISO `YYYY-MM-DD`；不用 Tab；值里不要换行。

## 各类型必填字段

| 类型 | 必填 |
| --- | --- |
| 协同单 / 回执 / 退回单 | 类型、单号、发起人、接收人、状态、更新 |
| 任务说明 / 输入清单 / 待裁决 / 过程记录 | 类型、任务、更新 |
| 工作台 | 类型、成员、更新 |
| 看板 | 类型、更新 |
| 任务状态 YAML | 任务、状态、更新（另有上游单据、阻塞原因、产出） |

## 校验

```bash
python3 05-工具箱/scripts/校验.py
```

`巡检.py` 也会跑同样的校验；有问题会列出文件和缺的字段。
