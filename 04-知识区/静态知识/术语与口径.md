# 术语与口径

## 术语

| 术语 | 含义 |
| --- | --- |
| 协同单 | 请别人办事的单据：委托产出、请求确认、请求裁决 |
| 回执 | 接收人办结后的答复；有产出附产出副本 |
| 退回单 | 接收人不能按单办理，或发起人验收不认可；必须写原因 |
| 正件 | 单据原件，留在发起人个人仓出件箱 |
| 指向消息 | 收件箱里的三行短消息：正件路径、动作类型、日期 |
| 归集 | 确认过的产出写进知识区 `current/` |
| 工作台 | 从个人仓任务状态生成的本人状态面板，放在公共仓推进管理 |
| 任务包 | 个人仓里装一个任务的六件套 |

## 口径

- 协同单由谁发出，就由谁收口。
- 点对点交换只走单据；单据只经个人仓出件箱/收件箱。
- 公共仓只记交易台账，不存正本。
- 保密数值只存在持有人个人仓；公共仓只写“由谁持有”，不写数值。
- 本演示项目：甲持有页面展示口径，乙持有机制口径；公共仓不写任何保密数值。
